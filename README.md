# Reverse Array Using Pointers in C

## Project Description

A simple C program that uses pointers to display the elements of an array in reverse order.

## Features

- Accept array elements
- Use pointers to access elements
- Display the array in reverse order

## Technologies Used

- C
- Pointers
- Arrays
- Loops

## How to Run

Compile and run the `reverse_array_pointer.c` file using a C compiler.
